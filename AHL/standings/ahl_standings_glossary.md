# AHL Standings Glossary

| Column | Description |
|---|---|
| Rank | League-wide standing rank. |
| Year | Season start year. |
| Season | Season label from source. |
| Division | Division label from source standings. |
| DivisionRank | Team rank within division. |
| Team | Team name. |
| GP | Games played. |
| W | Wins. |
| L | Losses. |
| OTL | Overtime losses. |
| SOL | Shootout losses (if present). |
| PTS | Points in standings. |
| PCT | Points percentage. |
| RW | Regulation wins. |
| ROW | Regulation and overtime wins. |
| GF | Goals for. |
| GA | Goals against. |
| DIFF | Goal differential (`GF - GA`). |
| L10 | Last 10 games summary. |
| STRK | Current streak summary. |
| PIM | Penalty minutes. |
| GR | Games remaining. |
