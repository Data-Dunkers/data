# NBA Standings Glossary

| Column | Description |
|---|---|
| Rank | League standing row order in source output. |
| Year | Season start year. |
| Conference | Conference label (`Eastern` or `Western`). |
| ConferenceRank | Rank within the conference in source order. |
| Team | Team name. |
| W | Wins. |
| L | Losses. |
| PCT | Win percentage. |
| GB | Games behind conference leader. |
| HOME | Home record summary. |
| AWAY | Away record summary. |
| DIV | Division record summary. |
| CONF | Conference record summary. |
| PPG | Points per game scored. |
| OPP PPG | Opponent points per game allowed. |
| DIFF | Point differential (`PPG - OPP PPG`). |
| STRK | Current streak summary. |
| L10 | Last 10 games summary. |
