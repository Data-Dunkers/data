# NHL Standings Glossary

| Column | Description |
|---|---|
| Rank | League standing row order in source output. |
| Division | Division label from standings section (for example `Atlantic`, `Metropolitan`, `Central`, `Pacific`). |
| DivisionRank | Rank within the division block in source order. |
| Team | Team name. |
| GP | Games played. |
| W | Wins. |
| L | Losses. |
| OTL | Overtime/shootout losses. |
| PTS | Points in standings. |
| RW | Regulation wins. |
| ROW | Regulation + overtime wins. |
| SOW | Shootout wins. |
| SOL | Shootout losses (may be blank in older seasons). |
| HOME | Home record summary. |
| AWAY | Away record summary. |
| GF | Goals for. |
| GA | Goals against. |
| DIFF | Goal differential (`GF - GA`). |
| L10 | Last 10 games summary. |
| STRK | Current streak summary. |
