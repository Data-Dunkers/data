# WNBA Standings Glossary

| Column | Description |
|---|---|
| Rank | League standing rank in source order. |
| Year | Season start year. |
| Team | Team name. |
| W | Wins. |
| L | Losses. |
| PCT | Win percentage. |
| GB | Games behind league leader. |
| HOME | Home record summary. |
| AWAY | Away record summary. |
| CONF | Conference record summary. |
| PPG | Points per game scored. |
| OPP PPG | Opponent points per game allowed. |
| DIFF | Point differential (`PPG - OPP PPG`). |
| STRK | Current streak summary. |
| L10 | Last 10 games summary (may be blank in early historical seasons where source omitted this field). |
