# MLB Standings Glossary

| Column | Description |
|---|---|
| Rank | League standing row order in source output. |
| Year | Season start year. |
| League | League label (`AL` or `NL`). |
| Division | Division label from source table (`East`, `Central`, `West`). |
| DivisionRank | Rank within the division in source order. |
| Team | Team name. |
| W | Wins. |
| L | Losses. |
| PCT | Win percentage. |
| GB | Games behind division leader. |
| HOME | Home record summary. |
| AWAY | Away record summary. |
| RS | Runs scored. |
| RA | Runs allowed. |
| DIFF | Run differential (`RS - RA`). |
| STRK | Current streak summary. |
| L10 | Last 10 games summary. |
