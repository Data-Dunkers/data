# MLS Standings Glossary

| Column | Description |
|---|---|
| Conference | Conference label from source standings table (for example `Eastern Conference` or `Western Conference`). |
| Rank | Conference standing rank in source order. |
| Year | Season start year. |
| Team | Club name. |
| GP | Matches played. |
| W | Wins. |
| D | Draws. |
| L | Losses. |
| F | Goals scored (for). |
| A | Goals conceded (against). |
| GD | Goal differential (`F - A`). |
| P | League points. |
