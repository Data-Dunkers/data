# NLL Standings Glossary

| Column | Description |
|---|---|
| Rank | Standings rank from source order (1 = best). |
| TeamCode | ESPN team abbreviation parsed from standings table. |
| Team | Team name. |
| W | Wins. |
| L | Losses. |
| PCT | Win percentage. |
| GF | Goals for. |
| GA | Goals against. |
| DIFF | Goal differential (`GF - GA`). |
