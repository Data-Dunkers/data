# NLL Team Stats Glossary

| Column | Description |
|---|---|
| Team | Team name. |
| Year | Season start year. |
| Season | Season label from source. |
| GP | Team games played (team-level season value). |
| G | Team goals scored. |
| A | Team assists. |
| PTS | Team points (`G + A`). |
| PIM | Team penalty minutes. |
| PPG | Team power-play goals. |
| PPA | Team power-play assists. |
| SHG | Team short-handed goals. |
| LB | Team loose balls recovered. |
| TO | Team turnovers. |
| CTO | Team caused turnovers. |
| BLK | Team blocked shots. |
| SOG | Team shots on goal. |
